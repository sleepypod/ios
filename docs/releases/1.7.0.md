# sleepypod 1.7.0

TestFlight build cut from `main` at tag `v1.7.0` (`43a0e3b`), which semantic-release created when release #99 merged. It groups the Watch movement actions, moves Snore detection to the settings sheet and adds a Movement chart to Compare with Apple Watch (#98). Not submitted for App Store review. The listing fields are unchanged from [1.3.1](1.3.1.md).

## TestFlight

### What to Test

```
- Settings sheet: Snore detection now sits under Watch movement, above Temperature control.
- Settings → Watch movement: Send all to pod and Export all are together under Actions, below the recordings.
- Sleep → Compare with Apple Watch: on a night with a Watch movement recording, a Movement chart shows the Watch against the pod.
- Light and dark mode throughout.
```

Internal testers need no review.
